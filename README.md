# سرور ناوا (مغز برنامه)

## راه‌اندازی سریع (هر سرور لینوکسی با Docker)
1. پوشه‌ی `server` را روی سرور کپی کنید.
2. در `docker-compose.yml` مقدار `ADMIN_PASSWORD` و `PUBLIC_URL` (آدرس دامنه با https) را بگذارید.
3. اجرا: `docker compose up -d --build`
4. پشت Nginx/Caddy با گواهی SSL قرار دهید (مثلاً Caddy: `nava.example.com { reverse_proxy localhost:8000 }`).
5. در اپ اندروید: تنظیمات ← پیشرفته ← آدرس سرور ناوا = `https://nava.example.com`
   (یا مقدار `DEFAULT_SERVER` در `Prefs.kt` را بگذارید و دوباره بیلد کنید).

## آدرس‌ها
- `/admin` پنل مدیریت (نام کاربری و رمز از تنظیمات Docker)
- `/app/` نسخه‌ی آیفون و وب (در سافاری: Share ← Add to Home Screen)
- `/api/...` API برنامه

## پنل مدیریت
آمار کاربران و فرمان‌ها · روشن/خاموش و فاصله‌ی تبلیغ · تبلیغ‌های داخلی (عکس/ویدیو، لینک، سقف نمایش، آمار نمایش و کلیک) ·
جایزه‌ی دعوت · قیمت طرح‌های اشتراک · ساخت کد فعال‌سازی پرو · هدیه‌ی پرو · اعلان داخل برنامه · آپدیت اجباری ·
فرمان‌های سفارشی · پاسخ‌های آماده · جوک‌ها · پرچم ویژگی‌ها · ویرایش JSON خام

## پرداخت اینترنتی (زرین‌پال)
بعد از ثبت‌نام و دریافت مرچنت از زرین‌پال (با هویت خودتان)، `ZARINPAL_MERCHANT` را بگذارید و در پنل «پرداخت اینترنتی» را روشن کنید.
تا آن موقع می‌توانید اشتراک را دستی بفروشید و «کد فعال‌سازی» از پنل بدهید.

## نکته‌ها
- داده‌ها در پوشه‌ی `data/` (SQLite) ذخیره می‌شوند؛ از آن نسخه‌ی پشتیبان بگیرید.
- صدای ابری با edge-tts ساخته و کش می‌شود؛ سرور باید به اینترنت خارج دسترسی داشته باشد.
